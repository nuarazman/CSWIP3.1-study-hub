Cloud sync setup

To sync across devices without email/password, create a free Supabase project, run the included SQL schema, then paste your project URL and anon/publishable key below. The app uses a long random recovery code as a secret. Anyone with that code can access your saved study data, so keep it private.

Recovery code

Create a new cloud vault on this device, or open a vault using a code you already saved. The code is shown only when created/opened; save it in a password manager or another safe place.

Your recovery code. Copy it now and store it safely. It cannot be recovered if lost.

Privacy & safety

  • Use only a recovery code you control; do not share it in screenshots or chats.
  • The app sends study progress and notes to your configured Supabase project when cloud sync is active.
  • Use a separate project for this personal dashboard. Never put a service-role key in this page.
  • Cloud sync requires an internet connection. Local mode works offline after the page is loaded, but does not sync.
  • This tool is a study organiser, not an official CSWIP resource or a guarantee of exam readiness.
